# Οδηγός ελέγχου TeamSuite

Διεύθυνση live: https://teamsuite-seven.vercel.app  
Σκοπός: να περάσεις **όλες τις επιλογές** της εφαρμογής με σταθερή σειρά. Κάνε hard refresh (Ctrl+F5) μετά από deploy.

Σημείωσε δίπλα σε κάθε γραμμή: **OK** / **Πρόβλημα** / **Δεν εφαρμόζει**.

---

## 0. Προετοιμασία

Χρησιμοποίησε δύο browsers ή ένα κανονικό + ένα παράθυρο ανώνυμο (ώστε να μην μπερδεύονται οι συνεδρίες).

| Ρόλος | Πώς μπαίνεις | Email DEMO |
|---|---|---|
| Διαχειριστής συλλόγου | Login → «Είσοδος DEMO παρουσίασης» ή email/κωδικός DEMO | `demo@teamsuite.app` / `demo1234` |
| Προπονητής | Login με | `coach@teamsuite.app` / `demo1234` |
| Γονέας | Login με | `parent@teamsuite.app` / `demo1234` |
| Platform admin | Ο δικός σου λογαριασμός πλατφόρμας | — |
| Ιατρός / αθλητής / γραμματεία | Τους δημιουργείς στο DEMO (ενότητα 3.2) | — |

Συσκευές: τουλάχιστον **desktop** και **κινητό** (ή DevTools → κινητό).

## 3. Διαχειριστής συλλόγου (DEMO)

Σύνδεση DEMO. Στο μενού πρέπει να φαίνονται σχεδόν όλες οι καρτέλες.

### 3.1 Επισκόπηση — `/`
- [ ] Κάρτες: ενεργοί αθλητές, προπονητές, τμήματα
- [ ] Ημερήσια έσοδα συνδρομών (αν υπάρχουν κινήσεις)
- [ ] Πίνακας τμημάτων: πλήθος αθλητών ως **αριθμός** (π.χ. `1`), όχι `1/18`
- [ ] Χωρίς οικονομικά στοιχεία αν έχουν αφαιρεθεί από την επισκόπηση
- [ ] Contrast quick-links / τίτλοι

### 3.2 Ρυθμίσεις → Χρήστες (πρώτα, για τους άλλους ρόλους)
Δημιούργησε δοκιμαστικούς λογαριασμούς στον DEMO:

| Ρόλος | Τι να ελέγξεις στη φόρμα |
|---|---|
| Ιατρός | Μόνο δικαίωμα «Αθλητές» (κλειδωμένο). Όχι οικονομικά/ρυθμίσεις |
| Γραμματεία | Πολλά δικαιώματα, όχι απαραίτητα όλα |
| Αθλητής | Σύνδεση με αθλητή από το μητρώο |
| Γονέας | Θα συνδεθεί στο 3.8 |
| Προπονητής | Σύνδεση με καρτέλα προπονητή |

- [ ] Πρόσκληση χρήστη, αντιγραφή κωδικού
- [ ] Επεξεργασία / απενεργοποίηση / διαγραφή
- [ ] Αλλαγή ρόλου σε ιατρό → εξαφανίζονται τα άλλα δικαιώματα

### 3.3 Αθλητές — `/athletes`
- [ ] Νέος αθλητής → ανοίγει προφίλ σε επεξεργασία

- [ ] Στήλη Γονέας (όχι κηδεμόνας)

**Γονείς**

**AMKA & Ταυτοποίηση**

- [ ] Χωρίς συγκατάθεση δεν αποθηκεύεται ΑΜΚΑ ανηλίκου

**Συνδρομές / Οφειλές**

- [ ] Καταγραφή αποδοχής DPA (ημερομηνία μένει)

**Backup**
- [ ] Λήψη backup συλλόγου
- [ ] Cloud sync (αν είναι ρυθμισμένο)

## 11. Τι δεν ελέγχεται από την εφαρμογή

- Νομικός έλεγχος κειμένων DPA / όρων (δικηγόρος)
- Πραγματική πληρωμή Viva live (μόνο demo, με δικά σου keys)
- Redis/cloud sync σε άλλη συσκευή, αν δεν υπάρχουν env vars στο Vercel

Αν κάτι αποτύχει, σημείωσε: **σελίδα, ρόλος, τι έκανες, τι περίμενες, τι έγινε, desktop ή κινητό**.
