# SportSuite 360 — GDPR Checklist (1 σελίδα)

**Ημερομηνία:** Αύγουστος 2026  
**Production:** https://sportsuite360.vercel.app  
**Στόχος:** νομική / επιχειρησιακή κάλυψη πέρα από τα τεχνικά μέτρα της εφαρμογής.

> Η εφαρμογή παρέχει τεχνικά εργαλεία GDPR. **Η νομική συμμόρφωση** ολοκληρώνεται με υπογραφές, σωστά στοιχεία επικοινωνίας και σωστή χρήση από κάθε σύλλογο.

---

## Α. Για τον δικηγόρο (επιμέλεια κειμένων)

Ελέγξτε / προσαρμόστε τα δημόσια κείμενα και in-app templates:

| Έγγραφο | Πού | Τι να επιβεβαιώσει |
|--------|-----|-------------------|
| Πολιτική Απορρήτου | `/legal/privacy` | Υπεύθυνος επεξεργασίας, σκοποί, δικαιώματα, υποεπεξεργαστές |
| Πολιτική Cookies | `/legal/cookies` | Κατηγορίες Essential / Analytics / Marketing |
| RoPA (άρθρο 30) | `/legal/ropa` | Πραγματικές δραστηριότητες επεξεργασίας |
| Data Breach Plan | `/legal/breach` | Ρόλοι, 72 ώρες, ΑΠΔΠΧ |
| Ενημέρωση πληρωμών | `/legal/payment` | Viva — χωρίς αποθήκευση κάρτας/CVV |
| DPA συλλόγου–πλατφόρμας | Ρυθμίσεις → GDPR | Ρόλοι ελεγκτή / εκτελούντος |
| DPIA (ΑΜΚΑ / ανήλικοι / υγεία) | Ρυθμίσεις → GDPR | Αν απαιτείται επίσημη αρχειοθέτηση |
| Όροι / συγκαταθέσεις | Ρυθμίσεις → Όροι, προφίλ αθλητή | Γονείς ανηλίκων, φωτο, ιατρικά |

**Συμπληρώστε στα κείμενα:** επωνυμία/ΑΦΜ πλατφόρμας, email DPO ή υπεύθυνου, στοιχεία συλλόγων όπου χρειάζεται.

---

## Β. Για τον ιδιοκτήτη πλατφόρμας (SportSuite / Vercel)

- [ ] Νομική επιμέλεια ολοκληρώθηκε (τμήμα Α)
- [ ] Στο Vercel Environment: `CRON_SECRET`, `SS360_SYNC_SECRET`, `SS360_SESSION_SECRET` (ή `SS360_AMKA_SECRET`), `BLOB_READ_WRITE_TOKEN`, Redis/KV
- [ ] Αν χρησιμοποιείτε Viva: ορίστε `VIVA_WEBHOOK_SECRET`
- [ ] Viva webhook URL:  
  `https://sportsuite360.vercel.app/api/viva/webhook?key=ΤΟ_SECRET`
- [ ] Επιβεβαίωση cron: backup + GDPR retention (ημερήσια)
- [ ] Ορισμός εσωτερικού υπευθύνου για αιτήματα GDPR / παραβιάσεις
- [ ] Σύντομο briefing προσωπικού (μην στέλνουμε ΑΜΚΑ/υγεία με email)

---

## Γ. Για κάθε σύλλογο (υπεύθυνος επεξεργασίας)

- [ ] Αποδοχή **DPA** στις Ρυθμίσεις → GDPR
- [ ] Έλεγχος μηνών διατήρησης δεδομένων + «Εφαρμογή διατήρησης» όταν χρειάζεται
- [ ] Συγκαταθέσεις αθλητών/γονέων στο προφίλ (προσωπικά, φωτο, gallery, επικοινωνία, ιατρικά, ΑΜΚΑ)
- [ ] Φωτογραφίες: μόνο αθλητές με photoUse + gallery
- [ ] Αιτήματα υποκειμένου (εξαγωγή / διόρθωση / διαγραφή / ανάκληση) από Ρυθμίσεις → GDPR → DSAR
- [ ] SMTP ενεργό μόνο για λειτουργικά emails· χωρίς ΑΜΚΑ/ιατρικά στο κείμενο
- [ ] Cookie banner: αποδοχή μόνο απαραίτητων αν δεν χρειάζονται analytics/marketing

---

## Δ. Γρήγορη δοκιμή μετά το go-live

1. Άνοιγμα `/legal/privacy` και `/legal/cookies` χωρίς login  
2. Cookie banner → Αποδοχή / Απόρριψη / Προσαρμογή  
3. Ρυθμίσεις → GDPR → αποδοχή DPA  
4. DSAR: εξαγωγή JSON για έναν αθλητή δοκιμής  
5. Upload φωτογραφίας χωρίς συγκατάθεση → πρέπει να απορρίπτεται  
6. (Προαιρετικά) Push mirror και επιβεβαίωση ότι ευαίσθητα πεδία κρυπτογραφούνται στο cloud  

---

## Ε. Τι θεωρείται «κλειστό» τεχνικά (χωρίς άλλο build)

Consent Manager, δημόσιες πολιτικές, DPA/DPIA UI, DSAR APIs, encryption mirror, photo consent gate, retention cron, email sanitizer + unsubscribe, Viva χωρίς PAN/CVV, tenant isolation στο sync.

**Υπόλοιπο:** νομική επιμέλεια + υπογραφές + σωστή καθημερινή χρήση.
