# Στόχος

Φτιάξε / ολοκλήρωσε την UI της TeamSuite_ver.3 ώστε να έχει ΑΚΡΙΒΩΣ τις ίδιες οθόνες, καρτέλες, φίλτρα, toolbars, φόρμες και επιλογές με την υπάρχουσα εφαρμογή TeamSuite.

Κανόνες ισοδυναμίας (υποχρεωτικοί):
1. Κάθε route παρακάτω υπάρχει με το ίδιο path (ή redirect ισοδύναμο, π.χ. /students → /athletes).
2. Κάθε καρτέλα, φίλτρο, κουμπί ενέργειας και πεδίο φόρμας που αναφέρεται ΕΔΩ υπάρχει με το ΙΔΙΟ ελληνικό label.
3. Δεν παραλείπεις οθόνες «για αργότερα». Αν κάτι λείπει = blocker.
4. Πριν κλείσεις μια οθόνη: άνοιξε τον αντίστοιχο φάκελο στο C:\TeamSuite\src\pages (ή component) και επαλήθευσε tabs/actions/fields από τον κώδικα — αυτό το έγγραφο είναι checklist· η πηγή αλήθειας για λεπτομέρειες πεδίων είναι ο παλιός κώδικας.
5. Module gates + role permissions όπως στην παλιά (RequireModule / δικαιώματα ρόλων).
6. Portals και public pages συμπεριλαμβάνονται.
7. Παράδωσε checklist ✅/❌ ανά οθόνη στο τέλος κάθε φάσης UI.

ΜΗΝ αλλάζεις το νόημα των επιλογών. Μπορείς να βελτιώσεις CSS/layout/grouped sidebar, ΑΛΛΑ όχι να κόψεις λειτουργίες ή πεδία.
