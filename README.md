# TeamSuite

Ενιαία εφαρμογή διαχείρισης ακαδημίας και ανάλυσης εσόδων–εξόδων.

## Τι περιλαμβάνει

### Διαχείριση ακαδημίας
- Μαθητές (μητρώο, κηδεμόνες, κατάσταση)
- Προπονητές
- Τμήματα / ομάδες
- Εβδομαδιαίο πρόγραμμα
- Παρουσίες

### Οικονομικά
- Καταχώριση εσόδων & εξόδων
- Καταστάσεις πληρωμών (πληρωμένο / εκκρεμές / ληξιπρόθεσμο)
- Ανάλυση με γραφήματα (μηνιαία ροή, κατανομή κατηγοριών)
- Καθαρό αποτέλεσμα & εκκρεμή υπόλοιπα

Τα δεδομένα αποθηκεύονται τοπικά στο `localStorage` με demo seed για άμεση δοκιμή.

## Εκκίνηση

```bash
npm install
npm run dev
```

Άνοιξε το URL που εμφανίζει το Vite (συνήθως `http://localhost:5173`).
